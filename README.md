# Data Cleaning & Reporting Automation

## Objective
Automate data cleaning and reporting workflows using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Features
- Removes duplicate records
- Handles missing values
- Cleans inconsistent data
- Generates automated reports
- Creates visual summaries

## Output Files
- cleaned_data.csv
- salary_report.png

## Learning Outcome
Understanding data preprocessing, automation, and reporting efficiency.
